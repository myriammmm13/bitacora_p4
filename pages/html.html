¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. Define la estructura del contenido mediante etiquetas.

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi Página</title>
  </head>
  <body>
    <h1>Hola Mundo</h1>
  </body>
</html>

Etiquetas principales

Estas son las etiquetas más usadas en HTML con su función:

Etiqueta Descripción
<html> Elemento raíz del documento
<head> Metadatos del documento
<body> Contenido visible de la página
<title> Título en la pestaña del navegador
<meta> Metadatos como charset o viewport
<h1> – <h6> Encabezados de nivel 1 al 6
<p> Párrafo de texto
<a> Enlace o hipervínculo
<img> Imagen
<ul> / <ol> Lista no ordenada / ordenada
<table> Tabla de datos
<form> Formulario
<input> Campo de entrada de datos

Etiquetas semánticas

Las etiquetas semánticas describen el significado del contenido, no solo su apariencia:

<header>
Encabezado de la página o sección
<nav>
Menú de navegación
<section>
Sección temática del contenido
<article>
Contenido independiente
<footer>
Pie de página
<main>
Contenido principal de la página, único por documento
