¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. Define la estructura del contenido mediante etiquetas.

Un ejemplo de la estructura de HTML es el siguiente:

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi Página</title>
  </head>
  <body>
    <h1>Hola Mundo</h1>
  </body>
</html>

Etiquetas principales

Estas son las etiquetas más usadas en HTML con su función:

Etiqueta Descripción
<html> Elemento raíz del documento
<head> Metadatos del documento
<body> Contenido visible de la página
<title> Título en la pestaña del navegador
<meta> Metadatos como charset o viewport
<h1> – <h6> Encabezados de nivel 1 al 6
<p> Párrafo de texto
<a> Enlace o hipervínculo
<img> Imagen
<ul> / <ol> Lista no ordenada / ordenada
<table> Tabla de datos
<form> Formulario
<input> Campo de entrada de datos

Tablas

Las tablas en HTML se utilizan para organizar y mostrar datos en filas y columnas. Son útiles cuando se desea presentar información estructurada, como horarios, listas o resultados.

Una tabla se construye utilizando etiquetas específicas como <table>, <tr> (filas), <td> (celdas de datos) y <th> (encabezados de columna).

Etiquetas semánticas

Las etiquetas semánticas describen el significado del contenido, no solo su apariencia:

<header>
Encabezado de la página o sección
<nav>
Menú de navegación
<section>
Sección temática del contenido
<article>
Contenido independiente
<footer>
Pie de página
<main>
Contenido principal de la página, único por documento

Formularios

Los formularios en HTML permiten recopilar información del usuario, como datos personales, mensajes o registros. Son utilizados en páginas web para interactuar con el usuario.

Se crean con la etiqueta <form> y pueden contener diferentes elementos como campos de texto, botones, listas desplegables y casillas de verificación.

Los formularios envían los datos al servidor mediante métodos como GET o POST.

Tipos de Input

El elemento <input> cambia su comportamiento según el atributo type. Estos son los más importantes:

Tipo Ejemplo de código Uso
text <input type="text"> Texto libre de una línea
email <input type="email"> Valida formato de correo electrónico
password <input type="password"> Oculta los caracteres escritos
number <input type="number"> Solo acepta valores numéricos
checkbox <input type="checkbox"> Casilla de verificación (sí/no)
radio <input type="radio" name="grupo"> Selección única dentro de un grupo
date <input type="date"> Selector de fecha
file <input type="file"> Permite subir archivos
submit <input type="submit" value="Enviar"> Botón para enviar el formulario

    <input type="radio" name="genero"> Opción B
