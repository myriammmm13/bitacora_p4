¿Qué es CSS?

CSS (Cascading Style Sheets) es un lenguaje utilizado para definir la apariencia y el diseño de una página web. Permite aplicar colores, fuentes, tamaños, espacios y distribuciones a los elementos HTML, mejorando la presentación visual del sitio.

Formas de aplicar CSS

Existen tres formas de agregar estilos a un documento HTML:

CSS en línea
Se aplica directamente en la etiqueta con el atributo style. 
<p style="color:red;">Texto</p>
CSS interno
Se escribe dentro de una etiqueta <style> en el <head>. 
<style>
  p { color: red; }
</style>
CSS externo
Se vincula un archivo .css separado con <link>. 
<link rel="stylesheet"
  href="style.css">

Selectores principales

Los selectores indican a qué elementos HTML se aplican los estilos:

Selector Ejemplo Descripción
Etiqueta p { } Aplica a todos los elementos <p>
Clase .card { } Aplica a elementos con esa clase
ID #menu { } Aplica a un elemento único con ese id
Descendente nav a { } Aplica a <a> dentro de <nav>
Pseudo-clase a:hover { } Aplica cuando el usuario pasa el mouse
Pseudo-elemento p::first-line { } Aplica a una parte específica del elemento

Propiedades principales

Las propiedades CSS definen cómo se verá un elemento en la página web. Las propiedades se escriben dentro de un bloque de reglas, con la sintaxis propiedad: valor;.

Existen cientos de propiedades, pero algunas de las más comunes incluyen:

  • color: Define el color del texto.
  • background: Define el fondo del elemento.
  • font-family: Define el tipo de letra.
  • font-size: Define el tamaño del texto.
  • margin: Espacio exterior entre elementos.
  • padding: Espacio interior dentro del elemento.
  • border: Define bordes alrededor del elemento.
  • width: Define el ancho del elemento.
  • height: Define la altura del elemento.

Ejemplo de uso:

/* Color y fondo */
color: #ffffff;
background: #000000;

/* Tipografía */
font-family: 'Poppins', sans-serif;
font-size: 1rem;

/* Espaciado */
margin: 20px;
padding: 10px;

/* Borde */
border: 1px solid purple;

/* Dimensiones */
width: 100%;
height: 200px;

Modelo de Caja (Box Model)

Todo elemento HTML es una caja compuesta por cuatro capas:

Content
El contenido real (texto, imagen)
Padding
Espacio entre el contenido y el borde
Border
El borde que rodea el padding
Margin
Espacio exterior entre elementos 
div {
  margin: 20px;
  border: 2px solid purple;
  padding: 15px;
  width: 300px;
}

Display y Position

Propiedad Valor Descripción
display block Ocupa todo el ancho disponible
inline Solo ocupa el espacio de su contenido
flex Activa el modelo Flexbox
position static Posición normal (por defecto)
relative Relativo a su posición original
absolute Relativo al ancestro posicionado más cercano
fixed Fijo en la pantalla al hacer scroll

Flexbox

Flexbox es un sistema de diseño que permite organizar elementos en una fila o columna de forma flexible. Facilita la alineación, distribución y adaptación de los elementos en diferentes tamaños de pantalla.

Se basa en un contenedor principal (flex container) y elementos hijos (flex items). 

.contenedor {
  display: flex;
  justify-content: center;  /* horizontal */
  align-items: center;      /* vertical */
  gap: 20px;                /* espacio entre hijos */
  flex-wrap: wrap;          /* permite salto de línea */
}
justify-content
Alinea elementos en el eje principal (horizontal por defecto)
align-items
Alinea elementos en el eje secundario (vertical por defecto)
flex-wrap
Permite que los elementos salten a la siguiente línea si no caben
